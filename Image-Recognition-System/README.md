# Image Recognition System Using Neural Network

## 1. Project Description

This project develops an AI-based Image Recognition System using a Convolutional Neural Network (CNN).

The system automatically classifies images into three categories:

- Animal
- Building
- Vehicle

The user provides an image, and the trained neural network predicts the category of the image along with its confidence score.

## 2. Problem Statement

Classifying a large number of images manually is time-consuming and can lead to errors. This project provides an automated solution using Artificial Intelligence.

The system learns visual features from training images and automatically identifies whether a new image belongs to the Animal, Building, or Vehicle category.

## 3. Objectives

- To develop an AI-based image classification system.
- To classify images into three categories.
- To use CNN for automatic feature extraction.
- To train the model using labelled images.
- To predict the category of a new image.
- To evaluate the performance of the trained model.
